# Localhost Temu proxy

Current release: **v47**, UV proxy with the local shopping companion. Double-click **Start proxy.cmd**, then open **http://localhost:3000/**. Keep the terminal window open while browsing; press Ctrl+C to stop. Alternatively use `npm start`.

V47 addresses two ways an old cart amount could remain stuck: a returning tab now rechecks a saved cart after a quiet period, and a successful cart edit acknowledgement without a full cart now triggers a full read even when the edit operation is omitted or newly numbered. Failed edit acknowledgements do not trigger a read. A page-client response only counts as refreshed once the worker has actually published its validated full cart. Saved-cart rechecks are limited to one attempt per account per 30 seconds; cart edits still prompt a fresh read. These changes passed the owned browser scenarios; the reported Samsung delete failure still needs a physical retest. The local server is stopped after this work; start it yourself with the command above.

V46 uses Temu's existing page client to request the full cart when that client is available. On the real Samsung homepage, that client returned the full cart in 519 ms without a cart-page visit. The companion now prefers this path, validates the complete response and saves it using the existing account-scoped database. Pages without that client retain the existing read path. A refused client read is not repeated through another path. All 97 tests and the controlled desktop/mobile scenarios pass, including add/remove through zero and navigation during a read. The integrated change still needs a real-phone check: the phone was disconnected on 21 October. This does not resolve the remaining puzzle/login failures or establish general mobile reliability.

## Current implementation

Ultraviolet 3.2.10 is the only installed rewriting engine. Its browser helpers keep navigation, requests, cookies, storage and workers in the virtual merchant context. The local Node relay preserves page-generated end-to-end headers and server cookies. Binary response transport removes response base64 encoding, with the JSON protocol retained for older open clients. A bounded public-static CDN cache stores eligible resources (32 MB / 256 entries, maximum one hour within upstream freshness). Account/cart/search APIs are excluded.

Version 22 streams successful image/font bodies without waiting for complete upstream downloads, propagates abandoned GET/HEAD cancellation, reuses helper packaging with file-change invalidation and ETag validation, and caches safe helper escaping. Executable/document rewriting and mutating requests retain the conservative paths. Only complete public streamed bodies up to 2 MiB are collected for caching; larger assets stream without accumulating a full cache copy. Limits and original response bytes remain enforced.

The user reports successful browsing, infinite loading, account creation and reaching the checkout page. A completed purchase has not been established. The companion reads supported real cart responses/cache and displays DZD estimates. No real local payment checkout or purchasing workflow is implemented.

Version 24 corrects nested localhost login return URLs, awaits response-cookie commitment before page initialization, uses the current virtual page URL for cookie writes and respects script-cookie deletion instead of restoring stale server copies. These are tested proxy corrections, not a claim that merchant token-touch HTTP424 or login requirements have been eliminated. Open the launcher and refresh documents after updates; server cookie jars are lost on restart.

This is a local-use release, not a public-production certification. The server is still loopback-only, capped at 100 sessions, with local diagnostics that must not be exposed as-is. Production session persistence and multi-user isolation remain future work. Live comparison testing encountered blank/loading pages, merchant API failures and login redirects in both v23 and v24; tests do not establish uninterrupted storefront compatibility or completed purchases.
